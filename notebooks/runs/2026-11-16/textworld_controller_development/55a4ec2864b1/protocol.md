# Develop a useful TextWorld controller

The completed [adapter calibration](../../notebooks/runs/2026-11-16/adapter_retention_calibration/b4ec292d870a/summary.md) has zero score and wins in all 256 TextWorld main episodes, including full memory. This development repairs the controller before proposing another retention comparison. It does not change the completed calibration, Conversation confirmation, their source identities or their conclusions.

## Diagnosis and permitted inputs

The old scripted selector ignores the visible quest instructions and selects the first admissible command absent from its retained action records. With no memory it repeatedly selects the same alphabetically early examination. Even full memory eventually exhausts those commands and repeats the first one; globally marking a command tried also prevents revisiting it in another location or later instruction. In saved seed 61000, full memory drops its potato, examines objects and travels before taking the quest key; it never unlocks and opens the box. Seed 61001 reaches the target room but leaves before taking the requested object. Seed 61002 opens and closes the cabinet without retrieving its target. These are diagnosed saved cases, not newly scored development cases.

The repaired scripted selector reads the ordered instructions printed before the first room. It grounds each instruction's action and object names in the currently admissible commands. It reconstructs progress from actual retrieved action records in timestamp order. An instruction can require a command already used earlier. The initial description carries the task; if that description is no longer available in the current observation or retrieved memory, there is no private cached plan or hidden history. If an instruction cannot be grounded, the existing untried-command fallback remains. This fallback can still loop or perform an irrelevant action; preserve those failures.

The controller supports the generated house grammar's default unblended, one-action-per-sentence instructions. Its verb handling follows the installed TextWorld house instruction grammar, including alternate wording for movement, taking, placement, locks and opening. It does not claim to understand arbitrary prose or blended compound quests. It receives no game metadata, solution walkthrough, policy commands, hidden logical facts or intermediate reward advice. Admissible commands are already supplied by the existing adapter; this remains an assisted text-game controller. The optional model path is outside this development and cannot enter the retained paired evidence.

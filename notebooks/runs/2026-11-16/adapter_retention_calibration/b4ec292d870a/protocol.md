# Calibrate the notebook retention comparison

This declaration extends the existing conversation, MiniGrid and TextWorld controllers to all nine memory-policy arms. It measures the outer-episode variation and the full cost of selecting a live prune with a verified replay. It is a calibration, with no claim that sixteen cases establish a performance advantage or equivalence. Commit the declaration and runner before executing any listed seed. Preserve every zero, adverse outcome and failed run; do not extend the seed list or tune the policy to obtain a gain.

## Episodes and memory arms

Use exactly seeds 61000–61015, one independent episode per seed and adapter. The reserved development and smoke seed is 60001. Conversation keeps its scripted literal-recall controller and eight steps. MiniGrid keeps the real MemoryS7 environment, masked initial cue, known-corridor controller and 100-step limit. TextWorld keeps the real generated three-room, five-object, three-command-quest game, scripted selector and 30-step limit. Generate one game per outer seed and pin its executable and metadata hashes immediately after generation. Require every main and replay arm to match that one identity, retain both files, and verify their hashes again before writing the completion marker. No model inference, prerecorded game trace or fallback can enter the result.

Run no memory and full memory once each, then FIFO, LRU, seeded random, explicit importance, learned utility, Diversity and measured retention at two and four slots. This gives 16 arms per adapter and seed, 768 main episodes in all. Random policy uses the outer seed, independently of the environment's own random generator. No memory admits each write and immediately discards it before a controller can read it. Full memory reserves six times the horizon plus sixteen slots and must finish with zero prunes; an insufficient capacity is an error. The same generous allowance admits no-memory writes before their immediate discard. Conversation and MiniGrid retain the existing 500 bytes per slot allowance; TextWorld remains slot-limited with no byte limit. Report actual usage and the configured allowance for every arm.

For explicit importance, freeze the controller's existing initial utility as the record's admission importance; later outcome learning still updates utility but cannot change importance. Other baseline rules remain their existing native implementations. The measured arm keeps causal weight 0.5 and the existing rule combining utility with beneficial measured effects per byte. No weight search or added posterior arm belongs to this calibration.

## Conditional removal at a live pruning decision

Use the [verified replay implementation](../../notebooks/_utils/adapters/live_retention.py). Reconstruct the same seed and all actual preceding pruning decisions. Match the complete recorded memory-call prefix, logical timeline, incoming write, credit inputs, budget and candidate metadata before intervention. Record UUIDs match by admission order. A missing or different boundary fails; it is not a zero effect.

For each candidate, the baseline uses FIFO at the pending write. The intervention removes that candidate first and then uses FIFO for any remaining overflow. Both continue under FIFO. The effect is baseline outcome minus intervention outcome. FIFO may itself remove the target, and replacements remain allowed. This measures removal under a bounded continuation policy rather than guaranteed retention versus removal. Signed effects remain visible even though the ranking only grants a bonus to beneficial retention effects.

The supported controllers are deterministic for the fixed outer seed and game. Execute exactly one pair per candidate. Repeating an identical continuation cannot add independent evidence, so give it no p-value, confidence interval or trial-count power claim. The uncertainty relevant to the later policy comparison comes from independent outer episodes. This calibration records that spread before a separate fixed confirmation declaration chooses its sample size for an explicitly stated planning effect. It does not infer an adoption threshold from the outcomes.

Reckon Python API
=================

This reference reads the core and memory API's signatures and docstrings from
the selected checkout. The Python package requires its compiled Rust extension;
the build does not substitute mock types for a missing extension.

Use the authored laboratory manual for worked integrations, experiment design
and interpretation. A supplied score, interface or threshold does not establish
that an intervention ran or identified a causal effect.
